# 百公里加速计时器

纯前端微信小程序，用于测量车辆 0-50 / 0-100 km/h 加速时间。

## 功能

- **自动模式**：GPS + 加速度计自动检测起步和到达目标速度
- **手动模式**：手动控制起止计时
- **历史记录**：本地存储，最佳成绩标记
- **速度融合算法**：GPS坐标自算 + 系统speed + IMU短时插值

## 速度获取方案

| 优先级 | 来源 | 说明 |
|--------|------|------|
| 1 | GPS Haversine 自算 | 坐标差÷时间，最稳定 |
| 2 | 系统 res.speed | 辅助参考 |
| 3 | IMU 加速度计插值 | GPS间隙补帧（≤1秒） |

## 过滤策略

- GPS精度过滤（accuracy > 50m 丢弃）
- 最小位移阈值（2m）
- 最小时间间隔（0.3s）
- 位移合理性校验
- 绝对速度上限 + 加速度上限
- 滑动窗口平滑（5点）
- 目标速度连续确认（200ms）

## 使用

1. 用微信开发者工具导入项目
2. 替换 `project.config.json` 中的 `appid`
3. 真机调试（GPS需要户外信号）
